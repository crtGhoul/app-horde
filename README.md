# ☣ APP_HORDE

A zombie/retro-hacking themed browser for iOS sideloading repos — 4,220 unique apps,
25,480 builds indexed across Alan's Gigantic Repo and the AppTesters IPA Repo, with
App Store verification, a beginner field manual, version picker, and favorites.

Live site: served via GitHub Pages from `index.html` (single self-contained file).

Built with the generator in `~/workspace/app-horde/` (not published here).
