# ☣ APP_HORDE

A zombie/retro-hacking themed index of iOS sideloading repos. Browse 4,200+ unique
apps (25,000+ builds) from Alan's Gigantic Repo and the AppTesters IPA Repo in one
fast, searchable, mobile-friendly page.

**Live site:** https://crtghoul.github.io/app-horde/

## What's inside

- 🔍 Search, categories, sorting, source filters, favorites (saved in your browser)
- ✅ App Store verification — real star ratings for 2,800+ apps, not made-up scores
- ☠ Risk signals — size anomalies, placeholder bundle IDs, repo-build vs App Store version checks
- 🕒 Freshness tracking — FRESH badges, sort by recently updated, weekly refresh countdown
- 📦 Per-app GET .IPA / .TIPA download buttons + version rollback picker
- 📖 FIELD MANUAL — beginner guide: Scarlet, AltStore, TrollStore, certificates, safety, troubleshooting
- ♻️ Index rebuilds automatically every Monday

## Disclaimer

Unofficial builds — do your own research, use at your own risk. This is an index that
links to third-party repos; it hosts no files. Corrections or removal requests:
[crtghoul on GitHub](https://github.com/crtGhoul).
