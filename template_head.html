0 · what is sideloading


☠ READ THIS FIRST

This site is an index, not a host. {{GUIDE_DISCLAIMER_SRC}} — I don't make, modify, or scan those files, and I can't vouch for any of them.


Do your own research before installing anything: confirm the bundle ID matches the real app ·
check which source it came from and how fresh the build is · google the tweak name for scam reports ·
never sideload banking, payment, or 2FA apps.


Not affiliated with Apple, the repos, or any app developer. Tweaked apps can be revoked, get accounts
banned, or be outright malware. Everything here is use-at-your-own-risk.



  
Normally your iPhone only installs apps from Apple's App Store. Sideloading means
  installing app files (.ipa files) from outside the App Store. The apps in this horde are
  tweaked builds — the original apps with mods like unlocked features or removed ads,
  uploaded by the repos.

  
You need an installer app on your iPhone to sign and install them. Four ways to do it below —
  pick the one that fits you. No computer at all? That's Path D if you're on iOS 27+.





1 · what's going on lately


// fresh intel — updated nov 8, 2026 · unconfirmed rumors are marked as such



  

  
☠ LiveContainer is back. After the official repo went dark earlier this month, LiveContainer's GitHub is publishing again — a fresh nightly landed Nov 8 with built-in JIT enabler support. If you downloaded the September build, update to the newest nightly from LiveContainer's official releases page. The known gotchas, from their GitHub issues and FAQ:

  
① Crash on launch on iOS 26.4+: update to the newest build (3.8.0 stable or a newer nightly). Older builds just die on new iOS.

  
② Built-in SideStore freezes or closes the second you open it: fixed in recent builds — update.

  
③ JIT apps fail with "Another LiveContainer is not installed": iOS 26 doesn't auto-detect the 2nd container. Open your 2nd LiveContainer app first, leave it running, then go back to the first. Also: JIT on iOS 26 needs the StikDebug app (free on the App Store) — the old airplane-mode JIT trick died in iOS 26.4.

  
④ SideStore won't sign in (ADI -45061 "device not provisioned", HTTP 503, or "-80045"/"-80046" errors): Apple's servers keep breaking old builds — the 503 failure was an Apple-side change that killed SideStore 0.6.4 and earlier, and 0.7.0-alpha or a newer nightly fixes it, so update SideStore first. The "-80045"/"-80046" sign-in errors are the same Apple backend flakiness in a new form: update your tool first, then wait a while and try once. Don't hammer retry — repeated failed sign-ins can lock your Apple ID ("-20209", "locked for security reasons"); if that happens, unlock it at iforgot.apple.com and use a spare ID, never your main. Still failing? Install and re-sign with iLoader 2.4.1 or newer from a computer instead — apps stay signed and launch fine even when SideStore's own UI is broken. Re-run iLoader every 7 days.

  
⑤ "Maximum number of installed apps using a free developer profile": that's the 3-app limit. Apps running inside LiveContainer don't count — only apps SideStore/AltStore install directly do. Delete one or move apps into LiveContainer.

  
☠ Apple is banning accounts for sideloading modded apps. Verified: Apple terminated paid developer accounts used to sideload modified YouTube/Twitter builds (reported Feb 2026 and again in 2026). This month, users installing on iOS 27 report "the provisioning profile is banned" errors mid-install (community-reported) — switching to a different Apple ID can fix it. AltStore 2.3.1+ now ships a "Randomize Bundle IDs" option for exactly this error — turn it on before installing new apps (it won't fix an ID that's already flagged). The pattern is real enough: this is exactly why survival rule ① below says use a spare Apple ID. Never sign with your main.

  
AltStore 2.3.2 is the latest: it fixes the "-80045" sign-in failures on Mac, plus background refresh and Remote AltServer setup on iOS 27 — update AltStore and AltServer (Windows 1.8.1 / Mac 1.8.3) before you troubleshoot anything else. Remote AltServer itself (from 2.3, Sept 30) still stands: after the first PC setup, install and refresh apps from anywhere over Wi-Fi — no more same-network refresh dance. If a remote refresh stalls, make sure LocalDevVPN is connected.

  
iOS 27.2 shipped Oct 26 — update your tools first, then update. It's now out for every iPhone that runs iOS 27 (including the new iPhone Duo). Sideloading tools are reported working on 27.2 with their latest builds (AltStore 2.3.2, SideStore nightly, iLoader 2.4.1+), so update those before you update iOS — and if your setup works today, there's no rush: big updates still break tools in waves, so check your tool's GitHub issues page first.

  
iOS 27.3 is in beta now (public beta Nov 5, full release expected in December). No sideloading breakage reported yet — but betas are for testers, not your daily phone. If your setup works, wait for the stable release, then update your tools first, same as always.

  
TrollStore reality check: official TrollStore still only supports iOS 14.0–17.0. Don't believe "TrollStore for iOS 26" videos — experimental forks exist but aren't proven on real devices. (Researchers demoed iOS 27 jailbreaks in October, and the researchers say 27.2 patches most of the bugs behind one demo — but none has a public tool. If a video promises one with no tool attached, it's fake.)

Costs a little · apps never expire · no weekly refresh

    
    
      
  1. Get a signing certificate from a signing service (the FastSign team behind Alan's repo runs one). It's usually a small yearly fee.
    2. 
      
  2. On your iPhone, install Scarlet from the download links below, then trust its profile in Settings → General → VPN & Device Management.
    3. 
      
  3. In Scarlet, import your certificate.
    4. 
      
  4. Browse this site, open any app, tap ⬇ GET, then open the downloaded file in Scarlet and install.
    5. 
    

  

  

    
free · you have a computer

    
PATH B — AltStore

    
Free · needs a Mac or Windows PC · refresh apps every 7 days · 3-app limit

    
    
      
  1. On your computer, install AltServer from the links below. On Windows you also need iTunes and iCloud from Apple's site (not the Microsoft Store).
    2. 
      
  2. Plug in your iPhone, open AltServer, and Install AltStore to your phone. Use a spare Apple ID if you like.
    3. 
      
  3. On your iPhone: Settings → General → VPN & Device Management → trust the profile. On iOS 16+, also enable Developer Mode in Settings → Privacy & Security.
    4. 
      
  4. Open AltStore → Sources tab → + → paste the source links from section 3. Now you can browse and install both repos right inside AltStore.
    5. 
      
  5. Refresh your apps every 7 days — with AltStore 2.3+ you can do it from anywhere over Wi-Fi via Remote AltServer after the first setup. Older versions need your phone on the same Wi-Fi as your computer.
    6. 
    

  

  

    
free · no computer · older iOS only

    
PATH C — TrollStore

    
Free · no computer · apps never expire · only iOS 14.0 – 17.0 (never 17.0.1+)

    
    
      
  1. Check your version: Settings → General → About → iOS Version. If it's 17.0.1 or newer, this path won't work — use A, B, or D.
    2. 
      
  2. Follow the official install guide linked below (TrollStore GitHub + ios.cfw.guide). It takes a few minutes.
    3. 
      
  3. Open TrollStore, tap +, and pick any .ipa you downloaded from this site. It installs permanently — no refresh, no revokes.
    4. 
    

  

  

    
free · no computer · iOS 27+

    
PATH D — SideInstaller + SideStore

    
Free · no computer at any step · refresh apps every 7 days · 3-app limit

    
    
      
  1. Check your version: Settings → General → About → iOS Version. You need 27.0 or newer. On 26 or lower, this path won't work — use Path B (one-time computer setup) instead.
    2. 
      
  2. Enable Developer Mode: Settings → Privacy & Security → Developer Mode → on, then restart when asked.
    3. 
      
  3. Get SideInstaller on your phone (video walkthrough linked below — grab the current download there) and run it. It installs SideStore directly on your iPhone: pairing and provisioning all happen on-device, no PC involved.
    4. 
      
  4. Trust the profile: Settings → General → VPN & Device Management → tap the SideStore profile → Trust.
    5. 
      
  5. Install WireGuard (free on the App Store) or LocalDevVPN, add the SideStore tunnel, and switch it on. SideStore needs the VPN active to sign apps — if your phone restarts, flip it back on.
    6. 
      
  6. Open SideStore → Settings → sign in with a spare Apple ID (never your main — see survival rule ①).
    7. 
      
  7. Install apps: browse this site, tap ⬇ GET on any app, then share/open the downloaded file in SideStore — or in SideStore tap + and pick the file. It signs and installs right on your phone.
    8. 
      
  8. Keep the VPN on and refresh before the 7-day expiry — SideStore re-signs over Wi-Fi by itself, no computer ever.
    9. 
    

    
Heads up: this route is new and community-reported — it works on iOS 27+ but hasn't been around long. If a step fails, check SideStore's GitHub issues before reinstalling everything.

7 · survival rules



  
① Use a spare Apple ID for signing — never your main one.

  
② Free Apple IDs expire every 7 days. Re-open AltStore/SideStore on Wi-Fi to refresh before apps die.

  
③ Free/shared certificates get revoked. If an app suddenly won't open, the cert died — re-sign it.

  
④ Tweaked ≠ official. Star ratings here verify the original app, not the modified build. Mods can get accounts banned.

  
⑤ Never sideload banking, payment, or 2FA apps from anywhere but the App Store.

  
⑥ If an app asks for logins it shouldn't need, delete it. When in doubt, check the uploader and the FRESH badge.





8 · when things break


// the errors every beginner hits, and the fix for each



  
✗ "Unable to Verify App"Your certificate was revoked or expired. Re-sign the app: in Scarlet re-import your certificate and reinstall; in AltStore/SideStore open the app and refresh. Free/shared certificates die often — this is normal.

  
✗ App installs but crashes instantlyThree usual causes: dead certificate (fix above), the build needs a newer iOS than you have (check REQUIRES iOS in the app's intel), or the tweak itself is broken. Try an older build from the version picker in the app's intel.

  
✗ AltStore says "Could not find AltServer"Your iPhone and computer must be on the same Wi-Fi, AltServer must be running, and iTunes (from Apple, not the Microsoft Store) must see your phone. Plug in with a cable once to re-pair.

  
✗ AltServer doesn't see my iPhoneUnlock the phone, tap Trust on both ends, and make sure Wi-Fi sync is enabled in iTunes/Finder. Restart AltServer if it still hides.

  
✗ "Developer Mode Required" (iOS 16+)Go to Settings → Privacy & Security → Developer Mode, turn it on, and restart when asked. Then trust the profile again.

  
✗ Scarlet / ESign itself won't openIts own certificate got revoked by Apple. Wait for the service to issue a new one, or switch to AltStore/SideStore with your own Apple ID.

  
✗ "App integrity could not be verified"Same as a revoked certificate — re-sign and reinstall the app.

  
✗ TrollStore won't install an appCheck your iOS version: TrollStore only works on 14.0–17.0, never 17.0.1+. Also use .tipa builds (marked TIPA in the version picker) for TrollStore-only apps.

  
✗ Download link is deadTry the other source's button in the app's intel, or pick an older build from the version picker. Repo CDNs move files around.

  
✗ "You hit the 3-app limit"Free Apple IDs can only keep 3 sideloaded apps active. Delete one in AltStore/SideStore to make room, or look into LiveContainer to bundle more.

  
✗ LiveContainer crashes on launch (iOS 26.4+)Update to LiveContainer 3.6.65 or newer — older builds crash on iOS 26.4+. Still failing? Reboot once and retry.

  
✗ "Another LiveContainer is not installed" (JIT apps fail)iOS 26 doesn't auto-detect the 2nd container. Open your 2nd LiveContainer app, leave it running, then go back to the first. JIT on iOS 26 also needs the free StikDebug app from the App Store — the old airplane-mode trick died in iOS 26.4.

  
✗ Built-in SideStore freezes or closes on launchUpdate LiveContainer to 3.7.2 or newer — that fixed the launch freeze / watchdog kill.

  
✗ SideStore won't sign in (ADI -45061 / HTTP 503 / -80045 / -80046)Update SideStore to 0.7.0-alpha or a newer nightly — Apple server-side changes broke 0.6.4 and earlier. Apple's backend has also been flaky lately, so some sign-in errors clear up on their own — wait a while and try once, don't hammer retry: repeated failed sign-ins can lock your Apple ID ("-20209"); unlock it at iforgot.apple.com. Community-reported fix that worked for several users: in SideStore settings turn off on-device Anisette, pick the "SideStore (New)" Anisette server, reset adi.pb, then sign in again. Still failing? Install and re-sign with iLoader 2.4.1+ from a computer instead; re-run iLoader every 7 days.

  
✗ "Failed to list developer app IDs" or other Apple server errors while installingCommunity-reported (Oct 2026): Apple's developer backend has been flaky — these errors can clear up on their own, so wait a while and retry. Still broken? Try a different network.

  
✗ "This NSPersistentStoreCoordinator has no persistent stores"Nightly-build bug when switching between SideStore and LiveContainer installs. Use the latest stable release instead of a nightly.





9 · verify before you install


// every app's intel panel runs these checks for you — here's what they mean, and what to check yourself



  
① Open the app's intel and read the VERIFICATION row. It automatically checks three things: whether the bundle ID matches a real App Store listing, how many independent repos carry the app, and whether the repo's build version lines up with the App Store's current release.

  
② Bundle ID must match. A ✓ means the ID belongs to the real app. ✗ means no App Store record exists — treat it with extra suspicion or skip it.

  
③ More repos beats one. An app listed by several independent repos is a weak positive signal. A lone upload to a single repo deserves a harder look.

  
④ The version must make sense. If a repo build claims a newer version than the App Store currently has, walk away — that's a classic fake. Older builds are usually just outdated.

  
⑤ Check the tweak name. The TWEAKS row says what's modified. Google "tweak name malware" and "tweak name scam" before installing anything that handles logins or money.

  
⑥ After downloading, check the file. A real .ipa is tens to hundreds of MB — a 2 MB "Spotify" is not Spotify. When your installer asks you to trust a certificate, make sure you recognize whose it is.

  
⑦ Nothing here proves safety. These checks catch fakes and sloppiness, not a well-made trojan. If an app asks for permissions or logins it shouldn't need, delete it.
